# 常见玩法链路审查与验收

日期：2026-09-07。验收入口是自然语言描述，核对实际DSL和执行行为；测试通过不代表支持全部纸牌玩法。

## 发现与修正

1. 原v0.1只能表达有限阶段和最高牌/手牌数计分，无法表达24点。加入带目标、牌值和运算限制的算式规则族与精确判题，而不是只改标题。
2. 原动作接口仅接收手牌下标。新增expression和declared_suit，前端提供算式输入、万能牌选花色、要牌和停牌。
3. 模型摘要可能与修复后的DSL不同。规则条款现在从最终执行配置生成，修复时带入用户要求；确认前执行启动检查。
4. 21点第一次真实生成失败，玩家配置混入旧版默认值。改用固定的两位参与者/各两张结构，其他可变人数玩法要求显式配置。重测通过。
5. 明确玩法原先也携带全部规则族schema；缩减为对应schema，约9965字符降到4063至4239字符。完整schema仍用于不明确的需求。
6. 玩家非法操作在状态副本上执行，不写回；隐藏信息玩法不向客户端暴露完整手牌、暗牌总点数或随机种子。
7. 接牌引擎已有非万能起始牌机制，但模型的能力说明遗漏，真实请求曾被误判为不支持。补齐固定执行语义和对应可见条款。
8. 恢复引擎时事件列表与原牌局共享引用，后续电脑回合失败可能污染内存事件。恢复入口改为深拷贝，并验证失败回合不提交任何动作、分数和事件。
9. 异常kind类型现返回明确校验错误；有万能牌的接牌规则要求发牌后至少留5张，避免剩余牌全是万能牌而无法翻出起始牌。

## 规则依据与变体

- [Pagat 24点](https://www.pagat.com/adders/24.html)：四数各用一次，加减乘除括号，精确24；页面列出A到10、含JQK等变体。本次验收明确为单人练习，不是多人抢答竞赛。
- [Bicycle Blackjack](https://bicyclecards.com/how-to-play/blackjack/)：牌值、要牌/停牌、庄家17及暗牌。本次明确为无下注练习，不含赌场下注、分牌、加倍和保险。
- [Pagat Crazy Eights](https://www.pagat.com/eights/crazy8s.html)：同花或同点、8指定花色、弃牌回收，以及强制出牌/持续摸牌的变体。本次明确2人各5张，不加特殊牌和喊牌惩罚。
- [Pagat 斗地主](https://www.pagat.com/climbing/doudizhu.html)、[Bicycle 德州扑克](https://bicyclecards.com/how-to-play/texas-holdem-poker/)用于确认当前缺少的组合牌型、阵营、叫牌、筹码及边池机制。

## 真实模型案例

使用用户已有系统凭据及 https://apipaths.com/v1。当前gpt-5.6-terra在24点请求45秒超时；gpt-5.5完成下列验收。中途存在上游502，失败记录保留在本机artifacts，不计作通过。

| 自然语言需求 | 最终结果 | 关键检查 |
|---|---|---|
| A到10的24点单人练习 | 已生成并运行 | 40张、四数各用一次、目标24、允许分数、随机有解/无解、3题 |
| 含JQK的24点变体 | 已生成并运行 | J=11/Q=12/K=13、只出有解题、2题 |
| 无下注21点 | 修正玩家结构后生成并运行 | 两位参与者各2张、软17停牌、自然21优先、3轮 |
| 疯狂八指定变体 | 已生成并运行 | 同花/同点、8指定花色、摸至可出、弃牌回收、先出完胜 |
| 三轮比大小 | 已生成并运行 | 原链路回归，2到A、每轮各出一张、3轮 |
| 完整斗地主 | 明确未支持 | 叫地主、阵营及组合牌型压制 |
| 完整德州扑克 | 明确未支持 | 下注轮、筹码、边池及七选五牌型 |

## 浏览器点击

- 24点：填写自然语言→真实模型生成→规则确认→模拟→试玩。第一题7/8/7/5，直接输入24被拒绝且状态不变，正确声明无解得1分。第二题2/5/8/8刷新后恢复，提交(5*8)-(2*8)得分。第三题5/7/8/8提交(7-5)*8+8，最终3/3分。截图artifacts/24-game-complete.png。
- 21点：从自然语言生成并确认模拟后开始试玩。第一轮17点停牌，庄家17点，平局；第二轮14点要牌至21点，对庄家18点获胜；第三轮20点停牌，庄家24点爆牌。最终玩家2分、庄家0分，暗牌在结算前隐藏。截图artifacts/blackjack-game-complete.png。
- 疯狂八：从自然语言重新生成，确认、模拟、试玩。界面禁用不合法牌，隐藏电脑手牌；实际点击验证同花/同点出牌、连续摸牌、8指定红桃/黑桃等动作。持续到牌堆耗尽，随后出完手牌获胜，共91个事件，玩家1分、电脑0分。此局结束前未触发弃牌回收，回收与全员阻塞另有确定性测试覆盖。截图artifacts/crazy-eights-game-complete.png。

## 限制

- 新规则族通过已有本机Web执行，暂不支持离线决策树导出；不宣称已生成可独立分发的新程序。
- 自然语言仍由外部模型理解，当前检查和测试不能证明任意描述均被准确实现。规则变体需要确认，模型服务仍可能超时或返回502。
- 没有增加训练、自对弈学习或多人联网。仿真仅用于确定性执行回归。
